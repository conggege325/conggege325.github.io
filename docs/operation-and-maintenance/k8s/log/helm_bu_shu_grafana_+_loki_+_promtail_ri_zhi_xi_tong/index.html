        介绍

        • Grafana 提供 Loki 中捕获的日志行的可视化与搜索平台。

        • Loki 是日志记录存储与检索引擎。

        • Promtail 做为日志采集器，抓取日志后，通过网关将它们推送给 Loki。

        Helm 的下载和安装

        Helm本质就是创建k8s集群及资源文件的管理工具

        下载地址：https://github.com/helm/helm/releases

        Helm 部署 Grafana + Loki + Promtail

        事先准备

        创建k8s命名空间

        1[zhangcong@master dev]$ kubectl create namespace logging

        添加仓库

        1[zhangcong@master dev]$ helm repo add grafana https://grafana.github.io/helm-charts
2
3[zhangcong@master dev]$ helm repo update

5[zhangcong@master dev]$ helm repo list

        部署** Loki **

        创建资源文件 value.yaml ，内容如下：

        1loki:
2  auth_enabled: false
3  commonConfig:
4    replication_factor: 1
5  storage:
6    type: 'filesystem'
7singleBinary:
8  replicas: 1

        部署：

        1[zhangcong@master dev]$ helm install --values values.yaml loki --namespace=logging grafana/loki

        修改Loki的StatefulSet

        说明：上面部署的Loki，是单机部署，使用的是有状态的服务，并且数据没有持久化。

        为了简单，把StatefulSet改成Deployment，并保存数据到主机目录。

        [zhangcong@master ~]$ kubectl edit statefulset.apps/loki -n logging

        • 把 kind: StatefulSet 改为 kind: Deployment

        • 去掉 persistentVolumeClaimRetentionPolicy 节点

        • 去掉 serviceName: loki-headless

        • 去掉 updateStrategy 节点

        • 去掉 volumeClaimTemplates 节点

        • 去掉最后面的 status 节点

        • 新增下面红色字体的部分

          volumes:

- emptyDir: {}

  name: tmp

    defaultMode: 420

    items:

    - key: config.yaml

      path: config.yaml

    name: loki

  name: config

- configMap:

    defaultMode: 420

    name: loki-runtime

  name: runtime-config

        ** - hostPath:**

        ** path: /home/zhangcong/dev/logging/loki**

        ** type: “”**

        ** name: storage**

        然后重新部署服务：

        [zhangcong@master ~]$ kubectl rollout restart deployment loki -n logging

        **部署 **Promtail

        Deployment 部署的副本 Pod 会分布在各个 Node 上，每个 Node 都可能运行好几个副本。

        DaemonSet 的不同之处在于：每个 Node 上最多只能运行一个副本。

        因此，使用DaemonSet部署Promtail

          1--- # Daemonset.yaml
  2apiVersion: apps/v1
  3kind: DaemonSet
  4metadata:
  5  name: promtail-daemonset
  6  namespace: logging
  7spec:
  8  selector:
  9    matchLabels:
 10      name: promtail
 11  template:
 12    metadata:
 13      labels:
 14        name: promtail
 15    spec:
 16      serviceAccount: promtail-serviceaccount
 17      containers:
 18      - name: promtail-container
 19        image: grafana/promtail
 20        args:
 21        - -config.file=/etc/promtail/promtail.yaml
 22        env: 
 23        - name: 'HOSTNAME' # needed when using kubernetes_sd_configs
 24          valueFrom:
 25            fieldRef:
 26              fieldPath: 'spec.nodeName'
 27        volumeMounts:
 28        - name: logs
 29          mountPath: /var/log
 30        - name: promtail-config
 31          mountPath: /etc/promtail
 32        - mountPath: /var/lib/docker/containers
 33          name: varlibdockercontainers
 34          readOnly: true

 36      - name: logs
 37        hostPath:
 38          path: /var/log

        示例：如果要增加读取文件的日志，可以在上面的 configmap.yaml 的 scrape_configs 节点下增加如下内容：

         1apiVersion: v1
 2data:
 3  promtail.yaml: |
 4    server:
 5      http_listen_port: 9080
 6      grpc_listen_port: 0
 7    clients:
 8    - url: http://loki-gateway.logging.svc.cluster.local/loki/api/v1/push
 9    positions:
10      filename: /tmp/positions.yaml
11    target_config:
12      sync_period: 10s
13    scrape_configs:
14    - job_name: app-logs
15      static_configs:
16        - targets:
17            - localhost
18          labels:
19            job: app-logs
20            __path__: /var/log/app-logs/**/*.latest.log
21      pipeline_stages:
22        - match:
23            selector: '{job="app-logs"}'
24            stages:
25              - multiline:
26                  firstline: '^time=\S+,host=\S+,app=\S+,level=S+'
27                  max_wait_time: 3s
28                  max_lines: 256
29              - regex:
30                  expression: '^time=(?P<time>\S+),host=(?P<host>\S+),app=(?P<app>\S+),level=(?P<level>\S+)\s+(?P<message>.*)$'
31              - labels:
32                  host:
33                  app:
34                  level:
35              - timestamp:
36                  source: time
37                  format: RFC3339Nano
38              - output:
39                  source: message
40    - job_name: pod-logs
41      ...............
42      ...............

        multiline 表示多行读取

        regex 表示读取的正则

        label 表示读取的标签

        timestamp 为时间采集

        output 表示输出的日志内容
