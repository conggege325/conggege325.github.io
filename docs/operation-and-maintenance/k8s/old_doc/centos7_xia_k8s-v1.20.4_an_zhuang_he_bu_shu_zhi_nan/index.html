          Centos7 下 K8s-V1.20.4 安装和部署指南

          2020年1月1日9 分钟阅读
          密码错误!
          您无权查看该文章。

          参考文档：

          https://www.runoob.com/docker/centos-docker-install.html

          https://blog.csdn.net/iqijun/article/details/106834220

          https://www.cnblogs.com/caoxb/p/11243472.html

          以下示例以三台centos7服务器为例：

          k8s-node1 节点： 192.168.128.21

          k8s-node2 节点： 192.168.128.22

          k8s-node3 节点： 192.168.128.23

          其中 node1 作为 mater 节点，node2、node3为 work 节点

          一、 环境配置：

          1. 设置主机名与时区
           1# 三台虚拟机都要执行
 2timedatectl set-timezone Asia/Shanghai
 3
 4# node1
 5hostnamectl set-hostname k8s-node1
 6
 7# node2
 8hostnamectl set-hostname k8s-node2
 9
10# node3
11hostnamectl set-hostname k8s-node3
          1. 网络设置

          设置静态ip (可选设置，但是建议设置，这样避免路由器分配ip的不确定)：

          IPADDR 根据实际主机设置即可

           1vim /etc/sysconfig/network-scripts/ifcfg-ens33
 2# 删除：
 3BOOTPROTO=dhcp
 4# 添加：
 5BOOTPROTO=static
 6# 根据实际 ip 设置
 7
 8IPADDR=192.168.128.21
 9NETMASK=255.255.255.0
10GATEWAY=192.168.128.2
11DNS1=114.114.114.114
12DNS2=8.8.8.8

          设置hosts：

          1vim /etc/hosts
2# 添加如下内容：
3192.168.128.21 k8s-node1
4192.168.128.22 k8s-node2
5192.168.128.23 k8s-node3
          1. 关闭防火墙、seLinux，三台虚拟机都要设置
          1sed -i 's/SELINUX=enforcing/SELINUX=disabled/g' /etc/selinux/config
2setenforce 0
3systemctl disable firewalld
4systemctl stop firewall
          1. 修改ssh配置，三台虚拟机都要设置
          1vim /etc/ssh/sshd_config
2# 修改如下内容：
3PermitRootLogin yes 
4PasswordAuthentication yes
          1. 关闭swap，三台虚拟机都要设置
          1vim /etc/fstab
2# 注释swap所在的行后，重启服务器
3/dev/mapper/centos-root /                       xfs     defaults        0 0
4UUID=d1565ba3-3ee6-446d-b166-b1ae84ab5080 /boot                   xfs     defaults        0 0
5# /dev/mapper/centos-swap swap                    swap    defaults        0 0

          或者临时关闭swap

          1# 时关闭swap
2swapoff -a
3
4# 查看swap是否关闭
5free -m
6              total        used        free      shared  buff/cache   available
7Mem:         997956      175388      200040        7800      622528      618800
8Swap:             0           0           0
          1. 将桥接的IPV4流量传递到iptables的链，三台虚拟机都要设置：
          1cat > /etc/sysctl.d/k8s.conf <<EOF
2net.bridge.bridge-nf-call-ip6tables = 1
3net.bridge.bridge-nf-call-iptables = 1
4net.ipv4.ip_forward = 1
5EOF

          应用规则：

          1sysctl -p

          二、 安装kubeadmin

          1. 每台服务器都安装Docker
          1yum install -y yum-utils
2yum-config-manager --add-repo http://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo
3yum install -y docker-ce docker-ce-cli containerd.io
4systemctl enable docker
5systemctl start docker

          docker配置：国内源（需要重启docker服务）

          1mkdir -p /etc/docker
2
3vim /etc/docker/daemon.json
4# 内容如下：
5{
6  "registry-mirrors":["https://docker.mirrors.ustc.edu.cn","https://registry.docker-cn.com","http://hub-mirror.c.163.com"],
7  "live-restore":true,
8  "exec-opts": ["native.cgroupdriver=systemd"]
9}
          1. 每台机器都安装kubeadm，kubelet和kubectl

          安装 helm

          Helm 是 Kubernetes 的包管理器

          下载地址：https://get.helm.sh/helm-v3.7.1-linux-amd64.tar.gz

          Helm 和 Kubernetes 的版本对应关系请查看：https://helm.sh/zh/docs/topics/version_skew/

          添加阿里云的k8s软件源

          1cat > /etc/yum.repos.d/kubernetes.repo << EOF
2[kubernetes]
3name=Kubernetes
4baseurl=https://mirrors.aliyun.com/kubernetes/yum/repos/kubernetes-el7-x86_64
5enabled=1
6gpgcheck=0
7repo_gpgcheck=0
8gpgkey=https://mirrors.aliyun.com/kubernetes/yum/doc/yum-key.gpg https://mirrors.aliyun.com/kubernetes/yum/doc/rpm-package-key.gpg
9EOF

          重建缓存

          1yum makecache

          安装kubeadm，kubelet和kubectl

          在部署kubernetes时，要求master node和worker node上的版本保持一致，否则会出现版本不匹配导致奇怪的问题出现。

          yum install -y kubelet- kubectl- kubeadm-

          例如：

23systemctl enable kubelet

          1. 在 master节点(即：node1)上部署Kubernetes

          在安装kubernetes集群之前，必须要提前准备好集群需要的镜像，所需镜像可以通过下面命令查看

          1[root@k8s-node1 ~]# kubeadm config images list
2k8s.gcr.io/kube-apiserver:v1.20.4
3k8s.gcr.io/kube-controller-manager:v1.20.4
4k8s.gcr.io/kube-scheduler:v1.20.4
5k8s.gcr.io/kube-proxy:v1.20.4
6k8s.gcr.io/pause:3.2
7k8s.gcr.io/etcd:3.4.13-0
8k8s.gcr.io/coredns:1.7.0

          k8s.gcr.io 被墙，无法连接，下面提供了一种替代方案：

          创建 init-k8s-images.sh，内容如下：

           1#!/bin/bash
 2
 3images=(
 4    kube-apiserver:v1.20.4
 5    kube-controller-manager:v1.20.4
 6    kube-scheduler:v1.20.4
 7    kube-proxy:v1.20.4
 8    pause:3.2
 9    etcd:3.4.13-0
10    coredns:1.7.0
11)
12
13for imageName in ${images[@]} ; do
14	docker pull registry.cn-hangzhou.aliyuncs.com/google_containers/$imageName
15	#docker tag registry.cn-hangzhou.aliyuncs.com/google_containers/$imageName 	k8s.gcr.io/$imageName
16	#docker rmi registry.cn-hangzhou.aliyuncs.com/google_containers/$imageName
17done

          如果之前已经安装过了k8s，先执行：

          1# 删除进程
2kill -9 <kubelet进程>
3
4# 删除配置文件
5rm -rf /etc/kubernetes/*
6rm -rf /var/lib/etcd
7
8# 重启服务等。。。
9swapoff -a && kubeadm reset  && systemctl daemon-reload && systemctl restart kubelet  && iptables -F && iptables -t nat -F && iptables -t mangle -F && iptables -X

          k8s 初始化

           1kubeadm init \
 2--image-repository registry.cn-hangzhou.aliyuncs.com/google_containers \
 3--apiserver-advertise-address=192.168.128.21 \
 4--kubernetes-version=1.20.4 \
 5--service-cidr=10.96.0.0/12 \
 6--pod-network-cidr=10.244.0.0/16
 7# --apiserver-advertise-address 本机ip，即网卡的地址
 8# --image-repository 国内仓库
 9# --kubernetes-version 指定k8s版本
10# --service-cidr 服务使用IP地址的替代范围
11# --pod-network-cidr 指定Pod网络的IP地址范围。如果设置，控制平面将自动为每个节点分配CIDR
